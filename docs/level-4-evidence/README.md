# Level 4 Evidence Pack

Collect real review artifacts here before the monthly deadline.

## Required Files

- `wallet-interactions.csv`: one row per real onboarded user wallet interaction.
- `feedback-summary.md`: summary of feedback themes and product decisions.
- Desktop product screenshot.
- Mobile product screenshot.
- Analytics or monitoring screenshot.
- Demo video URL in `docs/level-4-submission.md`.

## Wallet Interaction Proof Rules

Use only real Testnet wallet interactions from actual users. Each row should include:

- A real Stellar public key.
- The wallet used.
- The interaction type.
- A transaction hash when the user completed an on-chain check-in.
- A Stellar Expert transaction URL when available.
- Short consent notes, without private keys or sensitive personal data.

Do not include secret keys, recovery phrases, email addresses, phone numbers, or private user notes.
