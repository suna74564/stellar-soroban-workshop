# ProofBull Level 5 Growth Playbook

## Goal

Onboard at least 50 unique Stellar Testnet users who complete one real ProofBull check-in transaction and submit feedback through the Google Form.

## Audience

- Stellar and Soroban workshop participants.
- Hackathon builders testing wallet flows.
- Web3 learners who can install a Testnet wallet.
- Friends/community members willing to complete a guided five-minute flow.

## Acquisition Channels

| Channel | Action | Success Metric |
| --- | --- | --- |
| Workshop chat | Share deployed app, Google Form, and demo GIF/video. | 15 completed check-ins |
| Builder Discord/Telegram | Ask for five-minute Testnet UX feedback. | 20 completed check-ins |
| Personal network | Send direct test invite with wallet funding steps. | 10 completed check-ins |
| Demo session | Run live onboarding and collect hashes in real time. | 5 completed check-ins |

## Activation Script

1. Install or open a Stellar Testnet wallet.
2. Open ProofBull.
3. Connect the wallet.
4. Fund the wallet with the Friendbot shortcut if needed.
5. Complete one on-chain check-in.
6. Copy the transaction hash.
7. Submit the Google Form with rating and feedback.

## Retention Hypotheses

- Builders will return if reputation points visibly increase after repeat check-ins.
- Users will share feedback if transaction confirmation feels trustworthy and quick.
- Reviewers will trust the product more if wallet proof, event proof, and feedback proof are visible in one flow.

## Iteration Loop

Review responses after every 10 users:

- Tag each complaint as wallet, funding, confirmation, UI, value, or performance.
- Fix the top repeated issue before the next outreach wave.
- Add the fixing commit link to `feedback-iteration-summary.md`.
- Export the updated response sheet to the Level 5 workbook.
