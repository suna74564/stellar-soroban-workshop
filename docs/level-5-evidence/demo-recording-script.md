# Level 5 Demo Recording Script

Target length: 3 to 5 minutes.

## Recording Flow

1. Open the deployed ProofBull app.
2. Show the `Blue Belt // Level 5` header and the active Testnet user target.
3. Open the wallet selector and connect a real Testnet wallet.
4. Show account telemetry, network passphrase, and Testnet XLM balance.
5. If the wallet is unfunded, open the Friendbot shortcut and fund it.
6. Click `Check in on-chain` and approve the wallet signature.
7. Wait for the transaction status to move from signature to ledger confirmation.
8. Open the Stellar Expert transaction link from the transaction card.
9. Copy the transaction hash and explain that it goes into the Google Form.
10. Show the contract event tape and badge/reputation update.
11. Submit in-app feedback and then open the Google Form link if configured.
12. Show the monitoring strip: backend status, active wallet proof, check-ins, feedback, and errors.
13. Open the Level 5 evidence folder and show the feedback workbook, pitch deck, and wallet tracker.
14. End with the next roadmap items from `feedback-iteration-summary.md`.

## Reviewer Proof Shots

Capture these frames during or after the recording:

- Growth card showing active Testnet wallet count.
- Transaction card with a real Testnet transaction hash.
- Stellar Expert transaction page for the hash.
- Monitoring strip with backend online.
- Google Form response sheet or exported workbook.
- Pitch deck title slide.

## Do Not Show

- Secret keys or recovery phrases.
- Raw private feedback notes.
- Full email addresses in a public screenshot unless the users consented.
- Duplicate or self-generated transaction rows as real user proof.
